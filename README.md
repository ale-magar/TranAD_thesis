# TranAD Thesis

This repository contains the code developed for my Master’s thesis in Astrophysics
focused Enhancing the Transient gravitational-wave detection method through the utilization of Deep learning acchitecture (TranAD).

The project includes scripts and notebooks for correlated noise generation,
data preprocessing, signal injection, model training, and performance evaluation
on simulated gravitational-wave data.
